# 💰 Welth — Personal Expense Tracker

Welth is a personal finance mobile application built with **React Native** that helps users manage their expenses and interact with an AI assistant to make tracking their finances easier.

Users can record their expenses, keep track of their spending, and ask the assistant questions about their financial activity through a conversational interface.

## ✨ Features

- **Expense Management:** Add and record expenses to keep track of daily spending.
- **Expense Tracking:** Review recorded expenses and monitor spending over time.
- **AI-Powered Assistant:** Interact with an assistant through natural language.
- **Conversational Experience:** Ask questions and get assistance without relying entirely on manual navigation.
- **Mobile-First Experience:** Built with React Native for a mobile application experience.

## 🤖 AI Assistant

Welth combines expense tracking with a conversational assistant to make personal finance management more intuitive.

Instead of manually navigating through expense records for every question, users can interact with the assistant to get help with their financial activity.

The assistant is designed to complement the core expense-tracking experience by making financial information easier to access through conversation.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| **React Native** | Cross-platform mobile application development |
| **AI / LLM Integration** | Powers the conversational assistant |

## 🎯 Project Goal

The goal of Welth is to make personal expense management simpler by bringing expense tracking and conversational AI together in a single mobile application.
